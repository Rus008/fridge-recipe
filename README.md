# AI-Ассистент для Холодильника: От продуктов к рецептам

Этот проект представляет собой **бэкенд-сервис** для мобильного приложения (iOS), которое помогает пользователям получать рецепты на основе продуктов, имеющихся у них в холодильнике. Система использует **распознавание изображений** для идентификации продуктов и применяет **RAG (Retrieval-Augmented Generation)** для подбора и генерации релевантных рецептов.

---

## 🔑 Ключевые возможности
- **Генерация рецептов:** На основе списка продуктов пользователя система предлагает несколько подходящих рецептов.  
- **Семантический поиск:** Использует векторные представления (embeddings) для поиска рецептов, наиболее близких по составу к имеющимся продуктам, а не просто по точному совпадению.  
- **Детальная информация:** Для каждого рецепта предоставляется время приготовления, список ингредиентов, информация об аллергенах и пищевой ценности.  
- **Персонализация:** Учитывает только те продукты, которые есть у пользователя.  

---

## 🏗️ Как это работает (Архитектура)

### 1️⃣ Ввод данных (Мобильное приложение)
Пользователь с помощью iPhone фотографирует продукты в холодильнике. Приложение распознает их и отправляет список на бэкенд.

### 2️⃣ Детекция и распознавание
Модель детекции обнаруживает продукты на изображении, а затем распознает их названия.

### 3️⃣ Предобработка
Названия продуктов проходят лемматизацию и очистку от стоп-слов с помощью **spaCy**, чтобы унифицировать их для поиска.

### 4️⃣ Семантический поиск (RAG - Retrieval)
- Обработанный список продуктов преобразуется в эмбеддинги.  
- Этот вектор используется для поиска в векторной базе данных, где хранятся тысячи рецептов, также преобразованных в векторы.  
- Система находит *k* наиболее похожих рецептов (кандидатов) на основе **косинусного сходства**.

### 5️⃣ Генерация ответа (RAG - Generation)
- Найденные рецепты-кандидаты вместе с исходным запросом пользователя формируют промпт для большой языковой модели.  
- **LLM** генерирует удобный для пользователя ответ, предлагая на выбор несколько рецептов и кратко описывая их на основе предоставленного контекста.

## 🤖 Используемые модели и технологии

### 📌 Модели

#### `YOLO11n`
- **Тип:** Модель для детекции объектов.  
- **Назначение:** Распознает продукты на фотографиях холодильника.  
- Обеспечивает высокую скорость работы при небольшой модели, что делает её подходящей для мобильных и серверных приложений.  

#### `paraphrase-multilingual-mpnet-base-v2`
- **Тип:** Sentence Transformer модель.  
- **Назначение:** Преобразует названия ингредиентов в векторные представления (embeddings) для семантического поиска рецептов.  
- Многоязычная модель, эффективная для русского языка, и ключевой компонент retrieval-части в RAG.  

#### `OWLv2`
- **Тип:** Модель zeroshot-детекции объектов.  
- **Назначение:** Позволяет находить продукты даже без предварительно заданных классов, используя текстовые описания.  
- Особенно полезна для обработки новых или редко встречающихся категорий продуктов.  

#### `Gemini 2.5 Flash`
- **Тип:** Мультимодальная генеративная модель.  
- **Назначение:** Используется для генерации ответов на основе найденных рецептов и списка продуктов пользователя.  
- Поддерживает быстрый inference.
